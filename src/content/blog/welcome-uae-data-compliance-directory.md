If you run a business that touches the UAE, you have probably run into the same
wall we did: there is no single "UAE data compliance" rulebook. There is a
federal privacy law (the PDPL), a cloud framework from the TDRA, security
standards from NESA and DESC, sector rules from the Central Bank and the health
authorities, and separate regimes inside the DIFC and ADGM.

Working out which of those apply to a specific company is genuinely hard, and
most of the useful knowledge sits inside consulting firms.

This directory does two things:

1. **Explains each framework in plain English** - what it is, who it applies to,
   what it asks of you, and what happens if you ignore it.
2. **Lists the vendors who help** - compliance consultants, GRC firms, data
   centres, and DPO-as-a-service providers - so you can compare options instead
   of cold-googling.

Start with the [Compliance Checker](/checker) if you are not sure where you
stand.
